# Исправление: сильные подвисания при включении перемешивания и добавлении в очередь

## Корневые причины (по убыванию серьёзности)

1. **`updatePlaylist()` итерирует всю таймлайн ExoPlayer на главном потоке** — `PlayerViewModel.kt:345-376`. Перебор таймлайна (строки 347-361) выполняется синхронно на потоке вызова (Main, из listener `onTimelineChanged`). Для 10K+ треков это блокирует UI на 50-200мс при КАЖДОМ изменении таймлайна.

2. **`toggleShuffle()` пересоздаёт ВСЕ MediaItems с нуля** — `PlayerViewModel.kt:605-641`. Вызывает `createMediaItem()` N раз (каждый вызов создаёт Bundle + MediaMetadata + MediaItem), затем `controller.setMediaItems()` на Main. Для 10K треков: ~10K аллокаций объектов + перестроение таймлайна ExoPlayer — всё блокирует Main.

3. **Каскадный дублирующий `updatePlaylist()`** — После `setMediaItems()` / `addMediaItem()` срабатывает `onTimelineChanged` → `updatePlaylist()` запускается снова, вызывая второе полное перестроение таймлайна. Избыточно, когда мы только что сами установили элементы.

4. **`addToQueue()` вычисляет позицию вставки на Main, потом создаёт MediaItem на Default** — `PlayerViewModel.kt:519-534`. Позиция может устареть; `createMediaItem` выполняется на Default, хотя вычисление позиции уже было сделано на Main.

## Все изменения в одном файле

**Файл:** `app/src/main/java/com/nkds/hosikoouma/jasmine/viewmodels/PlayerViewModel.kt`

### Шаг 1: Перенести итерацию таймлайна с Main на фоновый поток в `updatePlaylist()`

Заменить строки 344-376 — вся итерация таймлайна переносится внутрь корутины:

```kotlin
private var updatePlaylistJob: Job? = null
private fun updatePlaylist() {
    val controller = controller ?: return
    if (skipNextPlaylistUpdate) {
        skipNextPlaylistUpdate = false
        return
    }
    updatePlaylistJob?.cancel()
    updatePlaylistJob = viewModelScope.launch(Dispatchers.Default) {
        val mediaItemsWithUids = mutableListOf<Pair<MediaItem, String>>()
        val timeline = controller.currentTimeline

        if (timeline.isEmpty) {
            for (i in 0 until controller.mediaItemCount) {
                val item = controller.getMediaItemAt(i)
                mediaItemsWithUids.add(item to item.mediaId)
            }
        } else {
            val window = Timeline.Window()
            for (i in 0 until timeline.windowCount) {
                timeline.getWindow(i, window)
                window.mediaItem?.let { mediaItemsWithUids.add(it to it.mediaId) }
            }
        }

        val items = mediaItemsWithUids.map { (item, uid) -> mediaToTrack(item).copy(uid = uid) }
        if (_playlist.value != items) {
            _playlist.value = items
            withContext(Dispatchers.Main) {
                updateCurrentTrack(controller.currentMediaItem)
            }
        }
    }
}
```

**Ключевой момент:** обновление `originalTrackList` в `updatePlaylist()` больше не нужно — оно управляется явно в `playTracks()` / `shuffleAndPlay()` / `toggleShuffle()`.

### Шаг 3: Переписать `toggleShuffle()` — переупорядочить существующие MediaItems

Заменить строки 145 и 605-641:

```kotlin
@Volatile
private var originalMediaItems: List<MediaItem> = emptyList()
```

```kotlin
fun toggleShuffle() {
    val controller = controller ?: return
    if (_isRadioMode.value || controller.mediaItemCount == 0) return

    val willEnable = !_shuffleModeEnabled.value
    val currentPos = controller.currentPosition

    viewModelScope.launch(Dispatchers.Default) {
        val reorderedItems: List<MediaItem>

        if (willEnable) {
            // Сохраняем текущие MediaItems как базовый (неперемешанный) порядок
            originalMediaItems = (0 until controller.mediaItemCount).map {
                controller.getMediaItemAt(it)
            }
            val order = QueueUtils.generateShuffleOrderStartAtZero(
                controller.mediaItemCount, controller.currentMediaItemIndex
            )
            reorderedItems = List(order.size) { originalMediaItems[order[it]] }
        } else {
            if (originalMediaItems.isEmpty()) {
                withContext(Dispatchers.Main) { _shuffleModeEnabled.value = false }
                return@launch
            }
            reorderedItems = originalMediaItems
        }

        val currentMediaId = controller.currentMediaItem?.mediaId ?: return@launch
        val newIndex = reorderedItems.indexOfFirst { it.mediaId == currentMediaId }.coerceAtLeast(0)

        withContext(Dispatchers.Main) {
            skipNextPlaylistUpdate = true
            controller.setMediaItems(reorderedItems, newIndex, currentPos)
            _shuffleModeEnabled.value = willEnable
            controller.shuffleModeEnabled = false
        }
    }
}
```

**Почему это быстро:** Ноль вызовов `createMediaItem()` — только извлечение существующих ссылок MediaItem из контроллера (O(n) копирование указателей) и их переупорядочивание через перестановку IntArray. Тяжёлое создание Bundle/Metadata полностью исключено.

### Шаг 4: Обновить `playTracks()` — сохранять MediaItems

```kotlin
fun playTracks(tracks: List<Track>, startIndex: Int, sourceName: String? = null) {
    val controller = controller ?: return
    _isRadioMode.value = false
    _currentSource.value = sourceName
    viewModelScope.launch(Dispatchers.Default) {
        val mediaItems = tracks.map { createMediaItem(it, sourceName = sourceName) }
        val savedRepeatMode = settingsRepository.repeatMode.first()
        withContext(Dispatchers.Main) {
            originalMediaItems = mediaItems
            skipNextPlaylistUpdate = true

            controller.shuffleModeEnabled = false
            _shuffleModeEnabled.value = false
            controller.repeatMode = savedRepeatMode
            controller.prepare()
            controller.play()
        }
    }
}
```

### Шаг 5: Обновить `shuffleAndPlay()` — сохранять оригинальные MediaItems

Заменить строки 459-478:

```kotlin
fun shuffleAndPlay(tracks: List<Track>, sourceName: String? = null) {
    val controller = controller ?: return
    _isRadioMode.value = false
    _currentSource.value = sourceName
    viewModelScope.launch(Dispatchers.Default) {
        val unshuffledItems = tracks.map { createMediaItem(it, sourceName = sourceName) }
        val shuffledItems = QueueUtils.fisherYatesCopy(unshuffledItems)
        val savedRepeatMode = settingsRepository.repeatMode.first()
        withContext(Dispatchers.Main) {
            originalMediaItems = unshuffledItems
            skipNextPlaylistUpdate = true
            controller.setMediaItems(shuffledItems, 0, 0L)
            controller.shuffleModeEnabled = false
            _shuffleModeEnabled.value = true
            controller.repeatMode = savedRepeatMode
            controller.prepare()
            controller.play()
        }
    }
}
```

**Примечание:** `QueueUtils.fisherYatesCopy` работает и с `List<MediaItem>` (generic `<T>`), просто переставляет ссылки.

### Шаг 7: Обновить `addToQueue()` / `addTracksToQueue()`

Заменить строки 519-551:

```kotlin
fun addToQueue(track: Track, showToast: Boolean = false) {
    val controller = controller ?: return
    if (_isRadioMode.value || controller.currentMediaItemIndex == -1) return
    val currentIndex = controller.currentMediaItemIndex
    viewModelScope.launch(Dispatchers.Default) {
        val mediaItem = createMediaItem(track, isManual = true, sourceName = _currentSource.value)
        withContext(Dispatchers.Main) {
            var insertPos = currentIndex + 1
            val currentList = _playlist.value
            while (insertPos < currentList.size && currentList[insertPos].isManual) { insertPos++ }
            controller.addMediaItem(insertPos, mediaItem)
            if (showToast) {
                _appToast.value = ToastData(track, ToastType.ADDED)
            }
        }
    }
}

fun addTracksToQueue(tracks: List<Track>) {
    val controller = controller ?: return
    if (_isRadioMode.value || controller.currentMediaItemIndex == -1) return
    val currentIndex = controller.currentMediaItemIndex
    viewModelScope.launch(Dispatchers.Default) {
        val mediaItems = tracks.map { createMediaItem(it, isManual = true, sourceName = _currentSource.value) }
        withContext(Dispatchers.Main) {
            var insertPos = currentIndex + 1
            val currentList = _playlist.value
            while (insertPos < currentList.size && currentList[insertPos].isManual) { insertPos++ }
            controller.addMediaItems(insertPos, mediaItems)
            if (tracks.isNotEmpty()) {
                _appToast.value = ToastData(tracks.first(), ToastType.ADDED)
            }
        }
    }
}
```
